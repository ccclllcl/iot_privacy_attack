# Results Structure Note

This file is kept as a short compatibility note for older result-directory documentation.

The final thesis delivery no longer uses the old `dataset_matrix` result package as the primary citation path. For the current delivery structure, use:

- `docs/REPOSITORY_DELIVERY_GUIDE.md`
- `outputs/reports/final_thesis/artifact_index.md`
- `outputs/reports/final_thesis/`
- `outputs/figures/final_thesis/`

The old `dataset_matrix` artifacts were process outputs from an earlier real-data matrix and have been cleaned from the tracked delivery tree when they were not referenced by `final_thesis` source paths. The current real-data result scope is:

- `outputs/reports/final_thesis/real/`
- `outputs/defense/final_thesis/real/`
- `outputs/defense/real_public_benchmark/`
